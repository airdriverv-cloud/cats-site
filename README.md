# Мир кошек

Статический сайт о кошках: породы, уход, питание, здоровье. Без сборки и зависимостей.

## Структура

- `index.html` — главная: статьи с поиском и фильтрами, таблица пород.
- `article.html` — шаблон статьи; текст и источники берутся из `data.js` по адресу `article.html?a=<slug>`.
- `data.js` — все статьи (`ARTICLES`) и иллюстрации (`PHOTOS`).
- `img/` — иллюстрации, лежат в репозитории и отдаются с самого сайта.
- `articles/` — редиректы со старых адресов на `article.html?a=<slug>`.
- `tools/gen-images.py` — скрипт, которым сгенерированы иллюстрации.
- `tools/check-site.py` — проверка: все картинки на месте, источники в статьях отвечают.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → branch `main`, folder `/root`).

## Иллюстрации

Все фото локальные: внешних ссылок на фотостоки больше нет. Картинки сгенерированы нейросетью
(Pollinations, модель sana) и сохранены в `img/` — по одному файлу на ключ из `PHOTOS`.
Водяной знак сервиса обрезается скриптом.

Перегенерировать все или отдельные картинки:

```bash
python tools/gen-images.py            # все
python tools/gen-images.py kitten vet # только выбранные
```

Сервис бесплатный и ограничен одним изображением в 45 секунд, поэтому полный прогон занимает
около 15 минут.
